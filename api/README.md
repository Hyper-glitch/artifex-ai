## Сервис: API

`API` — это `FastAPI` приложение с асинхронной архитектурой, реализующей взаимодействие с `PostgreSQL`, `RabbitMQ` и `Telegram-ботом`. Предназначено для регистрации пользователей, постановки задач генерации изображений и обновления их статуса.

### Переменные окружения
Создайте `.env` файл в директории api со следующим содержимым:

```env
AUTH_TOKEN=token  # Самостоятельно сгенерированный  надежный токен для авторизации других сервисов в API

POSTGRES_USER=user
POSTGRES_PASSWORD=password
POSTGRES_HOST=database
POSTGRES_PORT=5432
POSTGRES_DB=database

RABBITMQ_DEFAULT_USER=admin
RABBITMQ_DEFAULT_PASS=admin
RABBITMQ_HOST=rabbitmq
RABBITMQ_PORT=5672
RABBITMQ_HEARTBEAT=30
RABBITMQ_QUEUE_NAME="gen-ai-tasks"
```

⚠️ В контейнерной среде используйте `POSTGRES_HOST=database`, `RABBITMQ_HOST=rabbitmq`.

### Архитектура
Приложение построено по слоистой архитектуре:

- Слой репозиториев — отвечает за взаимодействие с базой данных.
- Слой сервисов — содержит бизнес-логику.
- DI-контейнер — используется для явной передачи зависимостей.
- Асинхронный продюсер RabbitMQ — отправляет задачи генерации в очередь gen-ai-tasks.

### Взаимодействие с RabbitMQ
API отправляет задачи генерации изображений в очередь RabbitMQ. Каждое сообщение содержит необходимые параметры для инференса. Ответ (результат инференса) позже обрабатывается worker-ом и отправляется в Telegram.

### Основные эндпоинты
**Пользователи (/users)**

- POST /users/sign-up/ — регистрация пользователя
- POST /users/sign-in/ — вход пользователя

**Задачи (/tasks)**
- POST /tasks/create/ — создать задачу генерации (отправляет сообщение в RabbitMQ)
- POST /tasks/update/ — обновление статуса задачи после инференса
